about=Simple Processing Toolbox tools for raster object and pixel analysis, including tiled SLIC and Quickshift. Install the plugin ZIP, then open Plugins > OBIA > Set up OBIA to install its raster analysis engine. Setup needs internet and additional disk space; it never installs packages into QGIS. Engine manifests cover Windows x64, Linux x64, and macOS Intel/Apple Silicon. Includes offline help and MIT-licensed OBIA source with upstream tiled Quickshift support. See the bundled verification record for tested platforms. Point-cloud and experimental deep-learning tools are outside this plugin.
